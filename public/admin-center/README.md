# Poké Center background

pokecenter-firered.png is the unscaled Pokémon FireRed/LeafGreen Pokémon Center
1F map (240 × 160 pixels), rendered from the original tile and layout data in
[pret/pokefirered](https://github.com/pret/pokefirered/tree/ce6406d8c2eaf46d543c8a2606de0c3cb1951982).

Source commit: ce6406d8c2eaf46d543c8a2606de0c3cb1951982

Source files:
- data/layouts/PokemonCenter_1F/map.bin (15 × 10 metatiles)
- data/tilesets/primary/building/{tiles.png,metatiles.bin,palettes/00.pal…06.pal}
- data/tilesets/secondary/pokemon_center/{tiles.png,metatiles.bin,palettes/07.pal…12.pal}

Tile layers use the original palettes and flip flags. No rescaling, invented
artwork, dialogue, trainers or NPC sprites are included. Keep CSS
image-rendering: pixelated when displaying it larger.

Original game artwork: Pokémon / Nintendo / Creatures Inc. / GAME FREAK.
The pret repository reconstructs the game data; it does not relicense this art.
